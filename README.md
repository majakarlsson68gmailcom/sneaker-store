# Stride – sneaker store (v0 experiment)

A sneaker web shop generated with [v0](https://v0.app), Vercel's AI app builder, during a group workshop where we tried out different AI tools. The goal was to see how far an AI tool can take a full-stack project, not to hand-write the code. Most of the code in this repo was generated by v0.

## What the shop does

- Six sneaker models, each with a product page, image gallery and size picker. Sizes that are out of stock are disabled.
- A cart that is saved in `localStorage`, so it remains after a page reload.
- Checkout through Stripe Checkout, with shipping to the Nordic countries.
- Sign-in with a magic link sent by email (Auth.js with Resend).
- Orders and users stored in a PostgreSQL database through Prisma.

The interface is in Swedish.

## Tech stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui · Prisma · PostgreSQL · Auth.js · Stripe · Resend

## Reviewing what v0 generated

I read through the generated code to understand how the parts fit together and where it holds up.

**What holds up**

- **Prices are checked on the server.** The checkout route (`app/api/checkout/route.ts`) ignores prices sent from the browser. It looks up each product, size and stock level in the server's own data before creating the Stripe session. Otherwise a visitor could change the price in the browser.
- **The Stripe key is only read on the server.** `lib/stripe.ts` is marked `server-only`, so the secret key never reaches the browser.
- **Guest orders are supported.** `userId` on `Order` is optional, so a purchase does not require an account.

**What is broken or missing**

- `middleware.ts` protects a `/konto` page and redirects there after sign-in, but no such page exists. A signed-in user ends up on a 404 page.
- Orders are never saved. The `Order` model exists, but nothing writes to it, since there is no Stripe webhook that confirms the payment.
- Stock is hard-coded in `lib/products.ts` and does not decrease after a purchase.
- Each product reuses the same image three times in the gallery.

## Running it locally

Requires Node.js, a PostgreSQL database and accounts with Stripe and Resend.

```bash
pnpm install
pnpm prisma generate
pnpm prisma db push
pnpm dev
```

Create a `.env.local` file with these variables:

```
DATABASE_URL=
AUTH_SECRET=
RESEND_API_KEY=
STRIPE_SECRET_KEY=
```

The shop pages work without Stripe and Resend. Checkout and sign-in need the keys.
